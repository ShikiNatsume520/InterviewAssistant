# 前端重构阶段 3：用户手工测试说明

## 1. 推荐启动方式

开发联调需要两个终端。

终端一，启动 FastAPI：

```powershell
cd E:\Code\InterviewAssistant
uv run uvicorn server.app:app --host 127.0.0.1 --port 8000 --reload
```

终端二，启动 React：

```powershell
cd E:\Code\InterviewAssistant\frontend
npm run dev
```

浏览器打开：

```text
http://127.0.0.1:5173
```

也可以测试生产构建：

```powershell
cd E:\Code\InterviewAssistant\frontend
npm run build
```

构建后重启 FastAPI，直接打开 `http://127.0.0.1:8000`。

## 2. 游客普通聊天

1. 首次打开应看到欢迎页。
2. 点击“新建会话”，进入 `/threads/:threadId`。
3. 点击左下角“模型配置”。
4. 填写 OpenAI-compatible Base URL、Model 和 API Key。
5. 发送普通问题。

预期：

- 用户消息显示在右侧。
- Main Agent 头像和“执行中”显示在左侧。
- 流式正文逐步出现。
- 完成后状态替换为“已完成”。
- 刷新页面后用户和 Agent 完整消息仍存在且不重复。
- 浏览器关闭会话后模型配置被清除；后端不会保存 API Key。

## 3. 多会话

测试：

- 连续创建至少三个会话。
- 在会话间切换。
- 刷新具体 `/threads/:threadId` 地址。
- 重命名会话。
- 删除一个非运行中的会话。

预期：

- URL 与当前会话一致。
- 每个会话的产品事件互相隔离。
- 刷新可以恢复当前会话。
- 重命名后侧栏立即更新。
- 删除后不会影响其他会话。

## 4. 停止与恢复

1. 发起一个响应较慢的请求。
2. 流式输出期间点击红色停止按钮。

预期：

- 临时 delta 立即从当前页面清除。
- 输入框恢复可用，已提交文本不会残留在输入框。
- 页面显示“已停止显示；后端将在当前节点结束后保存中断检查点”。
- 同步 LLM 调用不会在函数内部立即终止；完成当前节点后，Thread 变为“已中断”。
- 刷新或重新进入后显示持久化的中断状态，并可以点击“从最近检查点继续”。

## 5. RAG

在服务端 `.env` 已配置 SiliconFlow Embedding，并且公共知识库索引可用的前提下，询问一个能命中知识库的问题。

预期：

- RAG 作为 Main Agent 的折叠工具卡展示，不显示独立 Agent 头像。
- 回答正文正常显示。
- 回答下方出现“参考资料 N”折叠卡。
- 展开后显示文件名、起止行和引用片段。

## 6. 开发人员模式

启动 FastAPI 前设置：

```env
IA_DEV_MODE=true
IA_DEV_ACCESS_TOKEN=<你的高熵本地凭证>
```

预期：

- 左下角出现“开发人员登录”。
- 登录后显示“开发人员模式 · 使用服务端配置”。
- 不要求在浏览器填写模型 API Key。
- 页面不会显示 `.env` 中的实际 Key。
- 返回游客模式后恢复此前游客的 Thread。

## 7. 错误场景

建议验证：

- 游客未配置模型时点击发送。
- Base URL 不合法。
- API Key 错误。
- 模型名错误。
- 同一游客重复启动任务。
- 请求过程中模型服务断开。

预期：

- 缺少配置时打开配置弹层。
- HTTP/SSE 错误不回显 API Key、请求头或后端堆栈。
- 可重试错误显示“从检查点重试”。
- 并发任务返回明确冲突提示。
