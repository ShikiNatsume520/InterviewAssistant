# 简历模板参考

> 本文档供 Index Agent 索引、RAG 子图检索，作为简历优化时"好简历长什么样"的参考锚点。
> 简历模板分两类：技术岗（Spring/Python 后端）与算法岗。

## 技术岗简历模板

### 项目经历写法（STAR 法则）

**项目名称**  | 时间区间
- **背景**：项目服务于什么业务，解决什么问题
- **任务**：你负责的模块/职责
- **行动**：技术选型、架构设计、关键实现
- **结果**：可量化的业务/技术指标

示例：

> **订单中台重构**  | 2023.09 - 2024.01
> - 背景：原单体订单服务在促销峰值下 OOM，需拆分为微服务
> - 用 Spring Boot + MyBatis 实现订单拆分，支持读写分离与集群化的接口
> - 引入 Redis 缓存热点数据，接口响应时间从 800ms 降至 120ms
> - 用 RabbitMQ 做异步消息，订单超时取消等通过事件解耦，系统可用性提升至 99.9%

### 技能列表写法

- 与岗位相关优先，3-5 项为宜
- 区分"精通/熟悉/了解"层级，不要堆砌
- 示例：**熟悉** Java、Spring Boot、MyBatis；**了解** Go、Rust

## 算法岗简历模板

### 项目经历写法

**模型/系统名称**  | 时间区间
- **问题**：要解决的业务/学术问题
> - **方法**：模型架构、训练策略、关键创新点
> - **数据**：数据规模、标注方式、清洗策略
> - **指标**：精度/F1/延迟等可量化结果

示例：

> **多模态商品检索系统**  | 2023.03 - 2023.08
> - 用 CLIP 双塔结构做图文检索，在 200 万商品数据上训练
> - 引入对比学习 + hard negative mining，Recall@1 从 62% 提升至 78%
> - 用 FAISS 部署近似最近邻，检索延迟从 300ms 降至 20ms

### 技能列表写法

- 框架：PyTorch、HuggingFace、LangChain
- 工具：Ray、WandB、DVC
